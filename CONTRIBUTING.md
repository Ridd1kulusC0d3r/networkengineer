# Contribuir

1. Defina objetivo observável e limite de fidelidade.
2. Adicione um cenário com ID estável e versão em `src/scenarios.js`.
3. Separe evidência observada, hipótese e conclusão. Dados pessoais reais não são necessários.
4. Inclua pelo menos uma decisão inadequada com consequência e uma solução válida.
5. Nos casos OT, teste continuidade além de bloqueio. Nos casos CTI, teste incerteza e origem.
6. Adicione testes com resultado esperado independente e verifique preservação dos invariantes.
7. Atualize catálogo, contagens, documentação e referências. Execute `npm test` e `npm run build`.

Não anunciar suporte a protocolo apenas porque há uma explicação dele. Não apresentar casos sintéticos como eventos reais. Se incorporar código externo, documentar versão, caminho e licença.
