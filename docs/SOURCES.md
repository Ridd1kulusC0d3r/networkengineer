# Fontes e proveniência

Fontes consultadas em 19/10/2026 UTC. Evidências dos laboratórios foram escritas para treinamento: não são relatos de incidentes reais, indicadores acionáveis ou provas contra organizações.

| Tema | Fonte primária | Uso |
|---|---|---|
| Inspiração didática | https://github.com/peotta/Simul-Net | Organização de cenários e explicação visual; sem código incorporado |
| Simulação Linux no navegador | https://github.com/michael-borck/netsim | Benchmark de interação e exportação |
| Simulação web e PCAP | https://github.com/joxorsayan/netsim | Benchmark declarado pelo autor |
| DHCP | https://www.rfc-editor.org/rfc/rfc2131 | Referência de protocolo, não especificação completa do modelo |
| DNS | https://www.rfc-editor.org/rfc/rfc1035 | Referência de serviço |
| TLS | https://www.rfc-editor.org/rfc/rfc8446 | Contexto de canal autenticado; modelo não criptográfico |
| OT | https://attack.mitre.org/matrices/ics/ | Contexto de ameaças ICS; sem alegação de certificação ou cobertura de técnica |
| Falsos positivos CTI | https://www.misp-project.org/warninglists/ | Infraestrutura compartilhada e cautela com indicadores |
| Organização CTI | https://docs.opencti.io/latest/ | Referência de plataforma adjacente |
| Onion services | https://community.torproject.org/onion-services/overview/ | Caminho conceitual e identidade de serviço |
| Ausência de exit em onion | https://community.torproject.org/onion-services/talk/ | Distinguir acesso onion de saída para web pública |
| I2P | https://i2p.net/en/docs/overview/intro/ | Rede sobreposta e túneis |

As referências técnicas não são fontes dos registros fictícios E1/E2/E3. Não confundir uma citação de protocolo com confirmação de um incidente. Nenhuma referência endossa este projeto.
